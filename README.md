# NO MORE GRADIENTS

A reusable skill for building clean, accessible, responsive, and maintainable web applications.

## What it does

This skill helps AI coding agents:

* Build consistent and domain-specific UI
* Avoid generic AI-generated design patterns
* Follow good HTML, CSS, and component practices
* Handle responsive layouts and accessibility properly
* Manage loading, empty, error, and success states
* Keep code organized and maintainable
* Avoid unnecessary dependencies, animations, and abstractions
* Review and refine code before considering it complete

## Usage

[Download SKILL.md](./SKILL.md)
Add the skill to your AI coding agent's skills directory and use it when creating, modifying, reviewing, or refactoring web applications.
